# Synonymity

A fun word guessing game

Closeness is measured by how similar the dictionary **definitions** of the words are: each
word's definition (from the Open English Wordnet) is embedded, and similarity is the cosine
similarity of those definition embeddings. See [tools/word-data/README.md](tools/word-data/README.md).
